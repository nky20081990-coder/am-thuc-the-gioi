HUONG DAN SUA LOI STREAMLIT CLOUD

1. Mo repository GitHub cua ban.
2. Dat app.py va requirements.txt o THU MUC GOC cua repository.
3. Khong de app.py nam trong thu muc con "am-thuc-the-gioi" neu ban muon dung cau hinh Main file = app.py.
4. Xoa app.py cu, sau do upload 2 file moi nay.
5. Vao Streamlit Cloud > Settings/Manage app.
6. Main file path: app.py
7. Luu lai va Reboot app.

QUAN TRONG:
- app.py nay KHONG tao/xoa file trong /mnt/data.
- app chi dung Streamlit, khong can API key.
- requirements.txt da ghim Streamlit 1.65.0 de giam loi do thay doi phien ban.

Neu repository cua ban bat buoc phai giu thu muc con:
  Main file path = am-thuc-the-gioi/app.py
va app.py phai nam dung trong thu muc do.
